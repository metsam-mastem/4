A profile contains ID/version, exact expression, numeric approximation, precision, intended use, min/max scale, constraints, fallback, source note, tolerance, and enabled state.

Content-aware score:
J(r)=αEratio+βEoverflow+γEreadability+δEnavigation,
where Eratio=|log(ractual/rtarget)|. Weights are configuration, not universal constants. Reject layouts violating minimum font size, clipping, or interaction constraints.

Fibonacci grids may use bounded Fn/Fk values. Prime indices may distribute decorative markers or non-critical samples only; never alter IDs, payload order, cryptographic nonces, or provenance.

For a 3D atlas, cuboid dimensions a:b:c represent width:height:depth. Optimize readability, layer separation, navigation distance, collision count, information density, and source traceability.
