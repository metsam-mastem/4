# Visual Shadow Poster — Reproducible Prompt

Create a 16:9 scientific-art poster for SSG, titled “From Source to Visual Shadow”. Central composition: a luminous branching knowledge graph resembling a tree and fractal atlas, with file/document/code glyphs as nodes. Left side: hand-outline metaphor transforming into a multi-scale data poster. Right side: layers for source identity, graph, geometry, proportions, provenance chain, and reconstruction. Dark navy background with restrained gold, cyan, violet, and green. Clear legend and hierarchy; no illegible pseudo-text. Communicate that a poster is a projection, not the original source, and exact reconstruction requires a separate encoded payload and verification. Include √2, √3, √5, φ, π, Fibonacci, vector arrows, cuboid, and Merkle-style hash tree as motifs.

This is a reproducible prompt, not evidence that a binary image is committed.
